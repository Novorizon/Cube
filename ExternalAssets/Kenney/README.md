# Kenney 3D Asset Candidates

These packages are downloaded for evaluation before importing selected models into the Unity `Assets` folder.

Source: https://kenney.nl/assets

License: CC0 1.0. The downloaded packages include `License.txt` files that allow personal, educational, and commercial use. Crediting Kenney is appreciated but not required.

Downloaded packages:

| Package | Project use |
| --- | --- |
| fantasy-town-kit | Main base, warehouse, houses, shops, town props, road/wall pieces |
| building-kit | Generic modular building pieces |
| survival-kit | Workbench, tools, crates, barrels, gather/resource props |
| nature-kit | Trees, rocks, logs, flowers, bushes, terrain/nature props |
| food-kit | Food and crop props |
| pirate-kit | Pirate ships, docks, cannons, crates, invasion theme props |

Local paths:

- Archives: `D:\Cube\ExternalAssets\Kenney\Zips`
- Extracted files: `D:\Cube\ExternalAssets\Kenney\Extracted`
- Download manifest: `D:\Cube\ExternalAssets\Kenney\download_manifest.json`

Import guideline:

Only copy selected FBX/glTF files and required textures/materials into `Assets/Arts/...` after choosing final usage. Avoid importing all extracted packages into Unity at once.
