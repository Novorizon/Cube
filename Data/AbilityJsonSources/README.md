# Ability JSON Sources

This directory contains hand-authored complex ability sources. It is intentionally separate from
`Assets/Data/Json`, which is generated by Luban and may be overwritten.

Rules:

- `schemaVersion` must currently be `1`.
- Runtime enum values use `Game.Ability` enum values, not the legacy `skill*.xlsx` numeric mapping.
- Ability and modifier names are runtime internal names and must be globally unique after all
  providers are merged.
- A JSON ability may reference a public modifier from another provider by its exact name.
- Private modifiers and projectiles should use the document namespace as a prefix.
- Projectile references are local to one JSON document so the full projectile object is resolved
  before registration.
- Duplicate stable IDs or names across Excel and JSON are errors; load order never overrides data.

The `Samples` directory is documentation/test data and is not loaded automatically. A bootstrap or
middleware component must read an approved source and register `JsonAbilityDefinitionProvider`
with `AbilityManager` before `Initialize`.
