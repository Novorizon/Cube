# Modular Tile Prototype

This folder tests the Cube TD modular tile pipeline.

Assets:
- `TileBase_Prototype.glb` / `TileBase_Prototype.fbx`: shared stone and dirt base.
- `TileTop_Grass_Prototype.glb` / `TileTop_Grass_Prototype.fbx`: reusable grass top layer.
- `TilePreview_Base_Grass_Prototype.glb` / `TilePreview_Base_Grass_Prototype.fbx`: preview-only combined export.
- `TileBase_PaletteUV_Prototype.glb` / `TileBase_PaletteUV_Prototype.fbx`: base using palette UVs.
- `TileTop_Grass_PaletteUV_Prototype.glb` / `TileTop_Grass_PaletteUV_Prototype.fbx`: grass top using palette UVs.
- `TilePreview_Base_Grass_PaletteUV_Prototype.glb` / `TilePreview_Base_Grass_PaletteUV_Prototype.fbx`: preview-only palette UV export.
- `TileBase_Textured_Prototype.glb` / `TileBase_Textured_Prototype.fbx`: base using per-part albedo textures.
- `TileTop_Grass_Textured_Prototype.glb` / `TileTop_Grass_Textured_Prototype.fbx`: grass top using per-part albedo textures.
- `TilePreview_Base_Grass_Textured_Prototype.glb` / `TilePreview_Base_Grass_Textured_Prototype.fbx`: preview-only textured export.
- `TileTheme_GrassSoft_Clean.glb` / `TileTheme_GrassSoft_Clean.fbx`: grass-only theme test with a soft clean surface.
- `TileTheme_GrassSoft_Detail.glb` / `TileTheme_GrassSoft_Detail.fbx`: grass-only theme test with small stone and moss details.
- `ModularTilePrototype.blend`: source scene generated by `Tools/Art/generate_modular_tile_prototype.py`.
- `Textures/CubeTD_TilePalette.png`: small palette texture for tile materials.
- `Textures/T_GrassTop_Albedo.png`: soft grass color variation and small pebble specks.
- `Textures/T_GrassTheme_Clean_Albedo.png`: cleaner grass theme surface, closer to the plain reference.
- `Textures/T_GrassTheme_Detail_Albedo.png`: detailed grass theme surface, closer to the stone-speckled reference.
- `Textures/T_DirtSide_Albedo.png`: warm dirt color variation and subtle cracks.
- `Textures/T_StoneBase_Albedo.png`: dark stone variation and subtle cracks.
- `Textures/T_TileDetail_Grain.png`: optional gray detail texture for `CubeTD/LowPolyTextured`.
- `Shaders/CubeTD_LowPolyDiffuse.shader`: simple non-shiny diffuse/toon-ish shader.
- `Shaders/CubeTD_LowPolyTextured.shader`: non-shiny textured shader with optional detail map.
- `Shaders/CubeTD_SoftLitTexture.shader`: soft URP texture shader for Meshy/AI grass textures without oily specular highlights.

Shape:
- The grass top no longer uses separate bright marker blocks or pebble meshes.
- Small surface variation is kept in the texture so the tile stays clean in Unity.
- The `TileTheme_GrassSoft_*` assets are top-theme-only tests without the lower base.

Size:
- The modular base and top assets use the same 2.0 x 2.0 horizontal footprint.
- In Unity this should read as the same X/Z footprint after FBX axis conversion.

Material direction:
- These are low-shine PBR materials generated in Blender.
- Metallic is 0.
- Roughness is high.
- In Unity, keep Smoothness low if you recreate the materials manually.
- If Unity-generated materials look too shiny, create new materials with `CubeTD/LowPolyDiffuse`.
- Use `CubeTD_TilePalette.png` as a color reference or palette texture.
- For the `PaletteUV` models, assign `CubeTD_TilePalette.png` to `Base Map`.
- Set the palette texture Filter Mode to `Point` and disable mipmaps if colors bleed at distance.
- For the `Textured` models, create three Unity materials with `CubeTD/LowPolyTextured`:
  - Grass: `T_GrassTop_Albedo.png`
  - Dirt: `T_DirtSide_Albedo.png`
  - Stone: `T_StoneBase_Albedo.png`
- Assign `T_TileDetail_Grain.png` as `Detail Map` if the surface still feels too flat.
- For Meshy or AI-generated grass textures, try `CubeTD/SoftLitTexture`:
  - Ambient: `0.55`
  - Light Strength: `0.35` to `0.45`
  - Light Wrap: `0.30` to `0.45`
  - Max Brightness: `1.00` to `1.12`
  - Shadow Strength: `0.25` to `0.45`
  - Saturation: `0.90` to `1.05`

Pipeline note:
- Use the separate base and top assets for production tests.
- Use the preview asset only to inspect alignment quickly.
- Use the `PaletteUV` assets when testing the palette-texture workflow.
- Use the `Textured` assets when testing painterly surface variation.
