# Game Overview

本文记录项目整体方向，适合先了解“这个游戏要做什么”。

## 核心方向

玩家漂流到岛上后，进入长期岛屿经营和生存建设。项目同时保留独立塔防战斗模式，两者通过资源、奖励、剧情和进度连接，但运行时状态分开。

岛屿经营负责：

```text
长期资源和背包
工具和采集
农田和生产
建筑建造 / 升级 / 产出
科技树
任务和剧情入口
进入塔防前后的数据交换
```

塔防模式负责：

```text
单局波次
敌人
基地
防御塔
战斗内金币
塔防内建塔 / 升级 / 出售
结算奖励
```

## 当前开发重点

当前重点不是塔防战斗本身，而是岛屿经营主循环：

```text
开场 Story
  -> 接取第一个 Quest
  -> 采集资源
  -> 制作 Blueprint
  -> 建造 / 农田 / 工具 / 科技
  -> 解锁更多内容
```

## 设计边界

- 经营长期库存和塔防单局资源要分开。
- 配置可共享，但运行时状态不要混用。
- UI 类型按 `Docs/Architecture/UIFramework.md` 的 Page / Panel / Popup / Overlay / Toast 选择。
- 命名按 `Docs/Decisions/0001-naming-rules.md`，新代码默认不要加 `World` 或 `Game` 前缀。
